# Service Upgrade System — контекст для Claude

Telegram-бот приёма оплат **в долларах США на узбекскую карту**. Двуязычный (RU/EN), демо-режим.
Клиент в Узбекистане (получатель: ANZHE) принимает USD-переводы вручную; бот показывает реквизиты и собирает заявки об оплате.

**GitHub:** https://github.com/irekgai111-lang/payment-bot

## Стек

- Python 3.12, aiogram 3.27.0, python-dotenv 1.2.2
- SQLite (`payments.db`) — встроенная БД заявок
- Запуск: `python bot.py` из папки `service-upgrade-system/`
- PID-lock `bot.pid` против двойного запуска
- Rate limiting 3 сек между callback-запросами

## Файлы

- `bot.py` — хэндлеры `/start`, `/help`, `/stats`, выбор языка, список продуктов, карточка продукта, реквизиты, «Я оплатил»
- `config.py` — словарь `PRODUCTS` (двуязычные названия/описания), словарь `TEXTS` (RU/EN UI), чтение `.env`
- `.env` — `BOT_TOKEN`, `ADMIN_ID`, `CARD_NUMBER`, `CARD_HOLDER`, `CARD_TYPE`, `SUPPORT_PHONE` (в `.gitignore`)
- `payments.db` — SQLite (создаётся автоматически; в `.gitignore`)
- `plans/ROADMAP.md` — план доработок
- `docs/RESEARCH.md` — рыночное и техническое исследование (USD на UZ-карту, альтернативы)
- `docs/user-flow.md` — пользовательский сценарий

## Поток клиента

1. `/start` → выбор языка (🇷🇺 / 🇬🇧)
2. Список продуктов с ценами в USD
3. Клик по продукту → описание + цена + кнопка «💳 Оплатить»
4. Реквизиты карты ANZHE + кнопка «✅ Я оплатил»
5. Подтверждение клиенту + уведомление админу

## Демо-продукты (config.py → PRODUCTS)

- `product_1` — Demo Product A / Стартовый пакет — **$19.99**
- `product_2` — Demo Product B / Премиум пакет — **$49.99**

> Реальные продукты заказчик задаст позже. Цены, названия и описания меняются в `config.py`, перезапуск применяет изменения.

## Команды бота

- `/start` — выбор языка → список продуктов
- `/help` — справка на текущем языке
- `/stats` — pending-заявки (count + total), только `ADMIN_ID`

## Карта оплаты

VISA USD `4278 3200 2347 0544`, держатель `ANZHE` (Узбекистан).
Принимаем **только USD**. Криптой / другими валютами не принимаем.
Поддержка: `+7 927 479 3004`.

## Почему ручной перевод, а не эквайринг

- Российские провайдеры (ЮKassa, CloudPayments) не выплачивают на узбекские карты.
- Stripe не поддерживает Узбекистан как страну получателя.
- Payme/Click — только UZS, не USD.
- Единственный рабочий вариант: показ реквизитов USD-карты + ручная сверка в банковском приложении.
- Подробнее см. `docs/RESEARCH.md`.

## Правила

- ⛔ **НИКОГДА не удалять папку `.git`**
- НЕ коммитить `.env`, `payments.db`, `bot.pid`, `bot_logs.log`
- Этот проект живёт только в `service-upgrade-system/` — копий бота в других папках не создавать
- После каждого изменения: `git commit` + `git push origin master`
- Все сообщения в UI двуязычные (RU + EN), русский — обращение на «вы», английский — нейтральный
- Авто-выдача гайда **выключена**: после «Я оплатил» бот только уведомляет админа, никаких файлов не отдаёт без ручного подтверждения
