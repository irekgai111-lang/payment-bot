📖 ГАЙД ДЛЯ АДМИНИСТРАТОРОВ

Замени этот файл на свой PDF!

1. Найди файл guide.pdf в папке service-upgrade-system
2. Удали это текстовое сообщение
3. Поместишь свой PDF файл с именем guide.pdf

После этого клиенты смогут скачать гайд после оплаты!

---

Если у тебя нет PDF файла, преобразуй документ:
- Word → PDF (File → Export as PDF)
- Google Docs → PDF (File → Download → PDF Document)
- Любой формат → PDF (онлайн конвертер)

Важно: имя файла должно быть ТОЧНО "guide.pdf"
