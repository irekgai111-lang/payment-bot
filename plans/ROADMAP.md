# Roadmap Payment Bot

## Срочно
- [ ] Отозвать старый BOT_TOKEN в @BotFather и вставить новый в `.env`
- [ ] Подтвердить/скорректировать цены тарифов
- [ ] End-to-end тест: /start → выбор → реквизиты → «Я оплатил» → уведомление админу

- [ ] Кнопка «Написать автору» для вопросов
- [ ] Подтверждение/отклонение оплаты админом (кнопки в уведомлении)
