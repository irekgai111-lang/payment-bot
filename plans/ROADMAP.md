# Roadmap — Service Upgrade System

Демо-бот приёма USD-оплат на узбекскую карту ANZHE. Двуязычный (RU/EN), 2 демо-продукта.

## ✅ Сделано

- Выбор языка (RU/EN) при первом `/start`, запоминание на сессию, кнопка переключения языка
- Двуязычные названия и описания продуктов, двуязычный UI (`TEXTS` в `config.py`)
- Поток: язык → список продуктов → карточка продукта (описание + цена + «💳 Оплатить») → реквизиты карты → «✅ Я оплатил»
- 2 демо-продукта в USD ($19.99 / $49.99)
- Карта получателя: VISA USD `4278 3200 2347 0544`, ANZHE (Узбекистан)
- SQLite БД `payments.db` (таблица `payments`: user_id, name, username, product_name, amount, status, created_at)
- Уведомления админу: о новом клиенте на `/start` и о клике «Я оплатил» (с суммой/продуктом/временем)
- Команда `/stats` для админа (pending count + total в USD)
- Команда `/help` на текущем языке
- Rate limiting 3 сек между callback-запросами
- PID-lock `bot.pid` против двойного запуска
- `.gitignore` закрывает `.env`, `payments.db`, `bot_logs.log`, `bot.pid`
- Бот успешно запущен, токен в `.env`, ADMIN_ID настроен
- ⚡ Автозапуск через Windows Task Scheduler (задача `ServiceUpgradeBot`, триггер `AtLogOn`, авто-перезапуск 3× с интервалом 1 мин, защита от дубликатов)
- `start-bot.bat` — launcher: cd в папку, очистка stale `bot.pid`, запуск `python bot.py` с логированием в `bot_logs.log`
- Документация для оператора: `docs/OPERATIONS.md` (что делать ежедневно/при проблемах)

## 📌 Технический долг

- `user_products`, `user_lang`, `user_last_request` — в памяти процесса, теряются при рестарте. Перенести в SQLite.
- В `bot.py` нет хэндлера на «прочие» сообщения — клиент может зависнуть, если напишет текст вместо кнопки.
- `fmt_card()` рассчитан на любую длину, но не валидирует пробелы/буквы во входе. Сделать строгую валидацию при чтении `.env`.
- Цены и `TEXTS` хардкодом в `config.py` — если будет ≥3 языка или ≥5 продуктов, вынести в YAML/JSON.

## ⚠️ Известные ограничения

- Эквайринг (ЮKassa, CloudPayments, Stripe) к узбекской USD-карте **не подключается** — провайдеры не выплачивают на UZ-счета. Только ручной перевод.
- Клиентам из РФ перевести USD на UZ-карту сложно (нужен SWIFT / «Золотая Корона» / крипта) — это снижает конверсию.
- Telegram Payments официально Payme/Click не поддерживает, поэтому автоматизация UZS тоже отпадает.
