# User Flow — сценарий клиента

1. **Клиент жмёт /start**
   - Видит приветствие и кнопку «💳 Оплатить»
   - Админу приходит уведомление: «Новый клиент зашёл в бот»

2. **Клиент жмёт «💳 Оплатить»**
   - Видит список тарифов с ценами (инлайн-кнопки)

3. **Клиент выбирает тариф**
   - Бот показывает: название тарифа, сумму, номер карты, имя держателя
   - Две кнопки: «✅ Я оплатил» / «◀️ Назад»

4. **Клиент переводит деньги на карту и жмёт «✅ Я оплатил»**
   - Видит сообщение: «Спасибо, проверим в течение 15 минут»
   - Админу приходит уведомление: «Клиент оплатил! {имя} {@username} {тариф} {сумма}»

5. **Админ проверяет поступление на карту**
   - Если пришло — пишет клиенту лично и высылает гайд
   - Если не пришло — связывается с клиентом

## Точки роста
- Шаг 5 сейчас ручной → можно автоматизировать (см. plans/ROADMAP.md)
