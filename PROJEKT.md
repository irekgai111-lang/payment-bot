# Service Upgrade System — Telegram-бот для продажи гайда

## 📋 Описание
Telegram-бот для продажи онлайн-гайда **«Обучение администраторов»** от Энже Гайнемухаметовой.

Клиент выбирает тариф → бот показывает реквизиты карты → клиент переводит деньги → админу приходит уведомление.

## 🎯 Задача
- Автоматизировать продажу гайда через Telegram
- Упростить приём платежей (через ручной перевод на карту)
- Отправлять уведомления админу о новых клиентах и оплатах
- Предоставить несколько тарифных планов

## 💰 Тарифы
| Ключ | Название | Цена |
|------|----------|------|
| guide_basic | Гайд «Администратор с нуля» | 1 990 ₽ |
| guide_pro | Гайд PRO + чек-листы и шаблоны | 3 490 ₽ |
| guide_vip | VIP: гайд + разбор 1-на-1 (60 мин) | 6 900 ₽ |

## 🛠️ Технологии
- **Python 3.12** — основной язык
- **aiogram 3.27.0** — Telegram Bot API
- **python-dotenv 1.2.2** — управление переменными окружения
- **Защита от двойного запуска** — через PID-файл

## 📊 Функции
- **`/start`** — приветствие, объяснение
- **«💳 Оплатить»** — кнопка выбора услуги
- **Выбор тарифа** — inline кнопки с описанием
- **Показ реквизитов** — номер карты Visa + ФИО держателя
- **Подтверждение** — клиент нажимает «Я оплатил»
- **Уведомление админу** — информация о клиенте и оплате
