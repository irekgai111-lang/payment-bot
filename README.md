# Service Upgrade System — оплата гайда для администраторов

Telegram-бот для продажи гайда «Обучение администраторов» (автор: Энже Гайнемухаметова).
Клиент выбирает тариф → бот показывает реквизиты карты → клиент переводит и нажимает «Я оплатил» → админу приходит уведомление.

## Структура

```
service-upgrade-system/
├── bot.py            # основной код бота (aiogram 3.27)
├── config.py         # услуги, цены, переменные окружения
├── .env              # токен, ID админа, данные карты (НЕ КОММИТИТЬ)
├── .env.example      # пример .env для других разработчиков
├── .gitignore        # исключает .env, __pycache__, bot.pid, bot.log
└── requirements.txt  # aiogram==3.27.0, python-dotenv==1.2.2
```

## Запуск

```bash
cd C:\Users\Dell\Documents\project\service-upgrade-system
pip install -r requirements.txt
python bot.py
```

Защита от двойного запуска: создаётся `bot.pid`. Если бот уже запущен — второй экземпляр сразу выйдет с ошибкой.

## Текущие тарифы (config.py)

| Ключ | Название | Цена |
|------|----------|------|
| guide_basic | Гайд «Администратор с нуля» | 1 990 ₽ |
| guide_pro | Гайд PRO + чек-листы и шаблоны | 3 490 ₽ |
| guide_vip | VIP: гайд + разбор 1-на-1 (60 мин) | 6 900 ₽ |

Поменять цены/названия — в `config.py`, словарь `SERVICES`.

## Реквизиты (.env)

- `BOT_TOKEN` — токен от @BotFather
- `ADMIN_ID` — Telegram ID, куда приходят уведомления о клиентах и оплатах
- `CARD_NUMBER` — номер карты (16 цифр, без пробелов)
- `CARD_HOLDER` — имя держателя латиницей (сейчас: `ENZHE GAINEMUKHAMETOVA`)
