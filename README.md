# Service Upgrade System — Telegram бот для продажи услуг

Полнофункциональный Telegram бот для продажи двух вариантов продуктов через оплату на карту Visa.

## ✨ Что включено

- ✅ **Выбор продукта** — клиент выбирает один из двух вариантов
- ✅ **Приём платежей** — видит реквизиты → переводит сумму
- ✅ **SQLite БД** — все платежи сохраняются в `payments.db`
- ✅ **Автоматическая выдача** — клиент скачивает гайд после оплаты
- ✅ **Rate limiting** — защита от спама (5 сек между запросами)
- ✅ **Логирование** — все события записываются в логи
- ✅ **Команды:**
  - `/start` — начало, выбор продукта
  - `/help` — справка и контакты
  - `/stats` — статистика (только админ)

## 📊 Как это работает

### Клиент:
1. Открывает бота (`/start`)
2. Видит две кнопки с вариантами и ценами
3. Нажимает нужный вариант
4. Видит реквизиты карты с суммой
5. Переводит деньги на карту
6. Нажимает "✅ Я оплатил"
7. Получает кнопку "📥 Скачать гайд"
8. Скачивает PDF файл

### Админ:
1. Получает уведомление о платеже (имя, номер, продукт, сумма)
2. Проверяет карту (приходила ли сумма)
3. Готово! Платёж записан в БД

## ❓ Вопросы

**Q: Как менять названия вариантов?**
A: Открой `config.py`, найди `PRODUCTS`, измени `"name"` — сохрани, перезагрузи бота.

**Q: Где видеть все платежи?**
A: В файле `payments.db` (SQLite база данных).

**Q: Что если клиент не оплатил, но нажал "Я оплатил"?**
A: Админ проверит карту — денег не будет, но платёж записан в БД.

**Q: Как узнать статистику?**
A: Напиши боту `/stats` (если ты админ).
