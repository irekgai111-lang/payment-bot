# Service Upgrade System — Telegram бот для продажи услуг

Полнофункциональный Telegram бот для продажи гайда через оплату на карту Visa.

## ✨ Что включено

- ✅ **Приём платежей** — клиент вводит сумму → видит реквизиты → переводит
- ✅ **SQLite БД** — все платежи сохраняются в `payments.db`
- ✅ **Валидация** — минимум $1, максимум $10000
- ✅ **Rate limiting** — защита от спама (5 сек между запросами)
- ✅ **Автоматическая выдача** — клиент скачивает гайд после оплаты
- ✅ **Логирование** — все события записываются в логи
- ✅ **Команды:**
  - `/start` — начало
  - `/help` — справка и контакты
  - `/stats` — статистика (только админ)

## 📊 Как это работает

### Клиент:
1. Открывает бота
2. Вводит сумму: `50` (или `$100`)
3. Видит реквизиты карты
4. Переводит деньги на карту
5. Нажимает "✅ Я оплатил"
6. Получает кнопку "📥 Скачать гайд"
7. Скачивает PDF файл

### Админ:
1. Получает уведомление о платеже
2. Проверяет карту (приходила ли сумма)
3. Когда деньги поступили — данные платежа уже в БД (`payments.db`)

## ❓ Вопросы

**Q: Что если клиент не оплатил, но нажал "Я оплатил"?**
A: Он получит доступ к гайду, но когда админ проверит карту, денег не будет. Админ знает статус платежа.

**Q: Где видеть все платежи?**
A: В файле `payments.db` (SQLite база данных). Можно открыть в браузере или Python скриптом.

**Q: Как узнать статистику?**
A: Напиши боту `/stats` (если ты админ).

**Q: Что если гайда нет?**
A: Бот покажет ошибку и скажет написать в поддержку.

## 🚨 Важно

1. **Гайд должен называться `guide.pdf`** — без этого бот не найдёт файл
2. **Обновляй .env перед каждым запуском** — если токены изменились
3. **Чекируй логи** — если что-то не работает, смотри `bot_logs.log`
